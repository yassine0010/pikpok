# PikPok

PikPok is an online mobile app with a vertically scrolling puzzle feed. Users have accounts, submit answers, earn XP, and appear on a shared leaderboard.

## App features

- Signup and login for user accounts. Signup collects the user's age; age does not restrict access or feed content.
- A scrollable feed with empty puzzle cards for now.
- Answer submission will connect to a future puzzle API. Puzzle content and answer checking are not part of the current skeleton.
- Each user has an XP score shown on the online leaderboard.

## Tools

- **Mobile:** Expo, React Native, TypeScript, and Expo Router.
- **API:** Node.js, Fastify, and TypeScript.
- **Database:** PostgreSQL with direct SQL.
- **Packages:** npm.
- **Hosting:** The app and API will be online; the provider is undecided.
