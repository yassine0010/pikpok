# M1 — Mobile app skeleton

## Goal

Create the basic mobile app structure and navigation.

## Work

- Set up Expo, React Native, TypeScript, and Expo Router.
- Add signup, login, feed, leaderboard, and profile screens.
- Show empty puzzle-card placeholders in the scrolling feed.
- Apply the retained UI references to the basic screen layout.

## Done when

- The app opens and navigation between its screens works.
- The feed scrolls and displays empty cards without puzzle content.
