# M3 — XP and leaderboard

## Goal

Store each user's XP and show a shared online ranking.

## Work

- Add an XP score to each account.
- Add an API endpoint that returns users ranked by XP.
- Build the leaderboard screen and connect it to the API.
- Show the current user's XP in their profile.

## Done when

- XP is stored per user and the leaderboard displays the online ranking.
