# M2 — Online accounts

## Goal

Let users create accounts and sign in through the online API.

## Work

- Set up the Fastify API and PostgreSQL connection using direct SQL.
- Add signup, login, and private profile endpoints.
- Include an age field at signup as profile information only.
- Store account credentials securely.

## Done when

- A user can create an account, sign in, and access their own profile.
- The API and database are ready to run on an online host.
